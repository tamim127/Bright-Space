# 🚀 Overall Website Design Concept

### Design Direction

**Premium Dark + Futuristic + Minimal + Interactive**

* Background: `#050505` / `#080808`
* Primary text: `#F5F5F5`
* Secondary text: `#9A9A9A`
* Accent: একটি strong electric color, যেমন `#6C63FF` / `#00E5FF`
* Borders: subtle `rgba(255,255,255,0.08)`
* Glassmorphism খুব limitedভাবে ব্যবহার করবে
* Large typography
* Lots of negative space
* Smooth scroll animation
* Mouse-following subtle effects
* Magnetic buttons
* Project cards with hover interaction
* GSAP-style reveal animations
* Image/video-based case studies
* Minimal but premium navigation

**Overall feeling:**

> "We don't just build websites. We build digital products."

# 🔥 সবচেয়ে Important Design Principle

তোমার website-টা যেন **"আরেকটা dark agency template"** মনে না হয়।

তাই আমি এই visual hierarchy রাখতাম:

**70% — Minimal dark space**
**20% — Project visuals / UI screenshots**
**10% — Accent / glow / animation**

অর্থাৎ everywhere neon glow, glass card, gradient ব্যবহার করবে না।

**Premium agency website-এর secret হলো restraint.**
